个人简介

金彪，博士，福建师范大学高级实验师、硕士生导师。 主要研究方向包括隐私保护、数据挖掘以及 人脸图像软生物特征隐私增强等。

主要承担本科生 C 语言程序设计、C++ 面向对象程序设计、 Java 面向对象程序设计、操作系统、计算机科学导论等课程教学， 并承担研究生机器学习课程教学。

本主页用于集中展示个人科研、教学与学术服务成果。 论文、科研项目、专利、软件著作权及获奖情况均设置独立栏目， 后续可持续补充和更新。
