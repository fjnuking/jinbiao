# 金彪｜个人学术主页

这是一个为高校教师/科研人员设计的中文 GitHub Pages 个人学术主页。

## 已预设栏目

- 个人简介
- 教育经历与工作经历
- 研究方向
- 科研项目
- 学术论文
- 专利成果
- 软件著作权
- 获奖情况
- 教学与人才培养
- 学术服务
- 联系方式

每个科研成果栏目都已经预留了可复制的展示模板，后续只需要修改 HTML 内容即可。

## GitHub Pages 部署

1. 创建公开仓库：`你的GitHub用户名.github.io`
2. 上传 `index.html`、`style.css`、`script.js`
3. 进入 GitHub 仓库：
   `Settings → Pages`
4. 选择：
   `Deploy from a branch`
5. 选择：
   `main / (root)`
6. 保存并等待部署完成。

网站地址：

`https://你的GitHub用户名.github.io/`
